كيف تحول هذا المشروع إلى منصة للآخرين على GitHub مجاناً للأبد؟
  • 1. تحويل المستودع لقالب (Template): من إعدادات مستودعك في GitHub، فعّل خيار Template repository.
  • 2. استنساخ بضغطة زر: أي شخص أو عميل يريد صفحة شخصية يدخل على مستودعك ويضغط الزر الأخضر Use this template.
  • 3. النشر المجاني عبر GitHub Pages: يفعّل العميل خيار Pages من مستودعه ليحصل على رابطه المجاني مثل username.github.io أو يربط نطاقه الخاص.
  • 4. لوحة التحكم الفورية: يفتح العميل /admin.html ويدخل الـ Token الخاص به ويعدل بياناته وصوره وماريعه بنظام المعاينة الحية.
  • النتيجة: منصة كاملة تعمل لآلاف الأشخاص مجاناً 100% بدون أي تكلفة استضافة أو صيانة خوادم عليك!
