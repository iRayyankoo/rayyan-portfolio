منصة الأدوات والخدمات الذكية Ri88 SaaS

منظومة SaaS متكاملة تجمع أكثر من 50 أداة ذكية مجانية للمستخدمين في مكان واحد؛ تشمل الحاسبات المالية السعودية، معالجة ملفات PDF، تحرير الوسائط بـ WebAssembly، وأدوات المطورين، مع ضمان الخصوصية التامة عبر معالجة البيانات محلياً داخل المتصفح.

مستودع الكود على GitHub +50 أداة ذكية ومعالجة WebAssembly

01. سياق التحدي وتشتت أدوات الإنتاجية

يواجه المستخدمون ورواد الأعمال في السوق السعودي والمنطقة تشتتاً كبيراً عند إنجاز المهام الرقمية اليومية؛ حيث يضطر المستخدم للتنقل بين عشرات المواقع المنفصلة (لحساب ضريبة القيمة المضافة، جدول استهلاك القروض، حساب صافي الراتب والتأمينات، دمج وتعديل الـ PDF، وتحويل ملفات الفيديو والصور). غالبية هذه المواقع تفرض رسوم اشتراك باهظة، أو تغرق المستخدم بإعلانات مزعجة، أو تشكل مخاطر جسيمة على خصوصية البيانات برفع المستندات المالية والملفات الحساسة إلى خوادم سحابية خارجية مجهولة.

02. المعمارية التقنية والمعالجة الآمنة (Client-Side Computing)

بُنيت المنصة بأحدث إصدارات Next.js 16 App Router و React 19 مع TypeScript و Tailwind CSS v4. تمثل القرار الهندسي المحوري في اعتماد المعالجة الموضعية على جانب العميل Client-Side Processing باستخدام تقنية WebAssembly (WASM) عبر مكتبات @ffmpeg/ffmpeg و pdf-lib و Canvas API. نقل هذا المعمار عبء المعالجة الحسابية بالكامل لمتصفح المستخدم، مما وفر حماية مطلقة للبيانات دون رفع بايت واحد للخوادم (Zero-Cloud Retention)، وخفض تكاليف البنية التحتية والاستضافة إلى الصفر تقريباً.

03. هندسة واجهة المستخدم (Bento UI) والوصول السريع

صُممت المنصة وفق أحدث أنماط واجهات الويب Bento Grid Layout وتأثيرات زجاجية راقية Glassmorphism تدعم الوضعين الداكن والفاتح. زُوّدت المنصة بنافذة أوامر سريعة Command Palette (Ctrl+K) تتيح البحث الفوري والتنقل بين الأدوات في أجزاء من الثانية. كما دُمج نظام حسابات مرن عبر NextAuth.js مع قاعدة بيانات PostgreSQL عبر Prisma ORM لحفظ تفضيلات المستخدم والأدوات المفضلة، مع تجهيز خطة اشتراكات متقدمة (Pro Tier) عبر بوابة Stripe.

04. الأثر التشغيلي والنتائج الرقمية المحققة

أثبتت المنصة في إطلاقها التجريبي (Beta) قدرتها على أن تكون الوجهة اليومية الشاملة للإنتاجية، محققة وفورات زمنية ملحوظة للمستخدمين وتجربة استخدام خالية تماماً من الإعلانات أو الاحتكاك.

+50 أداة وحاسبة ذكية مفعلة مجاناً للمستخدمين
100% أمان وخصوصية عبر المعالجة المحلية (Client-Side)
<100ms زمن تنفيذ ومعالجة فوري داخل المتصفح

05. خارطة الطريق وتكامل الذكاء الاصطناعي

تشمل المرحلة القادمة تفعيل أدوات التلخيص الذكي وتحليل المستندات بواسطة نماذج الذكاء الاصطناعي (Smart AI Summarizer)، بالإضافة إلى إطلاق تطبيق الهاتف (Android APK & iOS PWA) وتوسيع حزم أدوات الأعمال الموجهة للشركات الناشئة في المملكة.

أبرز الخصائص
  • مكتبة تضم أكثر من 50 أداة متخصصة للمالية، المحتوى، والبرمجة.
  • معالجة ملفات الفيديو والوسائط محلياً بـ WebAssembly و FFmpeg.
  • حاسبات دقيقة مخصصة للأنظمة السعودية (الضريبة، الراتب، الزكاة).
  • نافذة أوامر سريعة (Ctrl+K) وتصميم Bento Grid عصري وسلس.
  • أمان مطلق وحفظ التفضيلات عبر NextAuth.js و Prisma ORM.
